# Dues & Contributions

A [Chickadee Bandit](https://chickadeebandit.com/app-library/dues-contributions) app.

Track organization dues collection — billing periods, per-member payment status, allocation rules that post immediately to reserve funds when dues are recorded, and period close reconciliation.

## Features

- Billing periods with per-member payment status.
- Allocation rules that post to reserve funds on record.
- Period-close reconciliation.
- Works with the Reserve Fund Dashboard.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-dues-contributions/releases/latest/download/bundle.json
```
